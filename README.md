# SevaSathi — responsive student project

## Files
- `index.html` — home, about, gallery, demo account, volunteer form and feedback form
- `services.html` — responsive services information page with photos
- `events.html` — responsive events/programme information page with photos
- `style.css` — shared responsive styling for desktop, tablet and mobile
- `script.js` — home page demo forms and local-browser storage
- `pages.js` — mobile navigation for Services and Events pages

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the top navigation to open Services and Events.

## Important
- This is a student prototype, not the official Sansthan website.
- Demo accounts and form entries are stored in `localStorage` on the current browser/device only. There is no Firebase/cloud backend; do not use real passwords or sensitive information.
- Official Sansthan images are hotlinked from `https://bhalchandramaharajsansthan.org/` and need internet access. Confirm permission before reusing images in a public deployment.
- Events page lists programme categories described by the official website, not verified upcoming dates. Check the official website for current announcements:
  https://bhalchandramaharajsansthan.org/
- Official sources consulted:
  - https://bhalchandramaharajsansthan.org/about-bhalchandra-maharaj/
  - https://bhalchandramaharajsansthan.org/about-us/social-work/
  - https://bhalchandramaharajsansthan.org/photo-gallery/
